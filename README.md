# Wordly Dictionary Pro

## Description
A Single Page Application (SPA) dictionary that allows users to search for word meanings, pronunciation, and examples using a free dictionary API.

## Features
- Word search functionality
- Definitions display
- Phonetic pronunciation
- Audio pronunciation (listen feature)
- Error handling for invalid input and missing words
- Loading indicator
- Clean responsive UI

## Technologies Used
- HTML
- CSS
- JavaScript (ES6)
- Dictionary API

## How to Run
1. Download or clone the project
2. Open `index.html` in a browser
3. Type a word and search

## API Used
https://api.dictionaryapi.dev/
